## Homework Pipeline

An AI-assisted dual-role pipeline for completing homework, defined in `homework_agent/homework.md` and accessible as a Claude Code slash command (`/homework`).

### How it works

1. **TA agent** reads the homework problems and lecture notes, then produces a principle-based grading rubric (checking criteria, not pre-computed answers).
2. **Student agent** reads the problems, lecture notes, and rubric, then writes a complete R Markdown solution.
3. **TA agent** reviews the solution against the rubric, independently verifying correctness by re-reading the lecture notes. Produces an item-by-item evaluation with line number citations.
4. **Student agent** revises based on feedback. Loop repeats up to 3 rounds or until the TA passes all items.

### Usage

```bash
# Specify a homework path
/homework p8131_biostats_methods_II/Homework 8

# Or run from within a homework directory (no arguments)
cd p8131_biostats_methods_II/Homework 8
/homework
```

### Design principles

- **Rubric = principles, not answers.** The TA rubric specifies *what to check* (e.g., "R code must match lecture sample code style"), not *what the answer should be*. This prevents correlated errors between the rubric and the solution.
- **Independent verification.** During review, the TA re-reads the lecture notes and homework PDF to verify correctness, rather than pattern-matching against the rubric.
- **Completeness via line citations.** The TA must cite specific RMD line numbers for each rubric criterion. If a step can't be located, it fails.

## Environment Setup

To knit the R Markdown files, the following software and packages are required.

### Software
- **R** (tested with R 4.5.1)
- **TinyTeX** or a full TeX distribution (for PDF output)

### R Packages

Install all required packages:

```r
install.packages(c(
  "rmarkdown", "knitr", "tidyverse", "broom", "dplyr",
  "ggplot2", "ggrepel", "glmnet", "janitor", "maps",
  "MASS", "modelr", "patchwork", "readxl", "scales",
  "nlme", "lme4", "pscl"
))

# For P8105 Data Science assignments
install.packages("devtools")
devtools::install_github("p8105/p8105.datasets")

# For PDF output
install.packages("tinytex")
tinytex::install_tinytex()
```
